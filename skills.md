# skills.md

## Habilidades operativas del proyecto

Este archivo define las capacidades practicas que pueden aplicarse sobre la web actual de `Impulsa Social`.

## 1. Contenido comercial

### Objetivo

Redactar y optimizar mensajes orientados a conversion para servicios de marketing digital.

### Entradas

- Tipo de servicio
- Publico objetivo
- Objeciones frecuentes
- Propuesta de valor
- CTA principal

### Salidas

- Titulares
- Subtitulares
- Beneficios
- Descripciones de servicios
- FAQs
- Testimonios redactados o refinados

### Uso esperado

- Mejorar `index.html`
- Ampliar `services.html`
- Ajustar `social-media.html`
- Reforzar `faq.html` y `testimonials.html`

## 2. Optimizacion UX y conversion

### Objetivo

Mejorar la experiencia de usuario para aumentar solicitudes de presupuesto y clics en CTA.

### Entradas

- Estructura de pagina
- Jerarquia visual
- Ubicacion de CTA
- Fricciones detectadas

### Salidas

- Reordenacion de bloques
- CTA mas visibles
- Formularios mas claros
- Mejoras de navegacion
- Ajustes responsive

### Uso esperado

- Refinar home, pricing y contacto.
- Reducir pasos hasta la conversion.

## 3. SEO on-page

### Objetivo

Mejorar visibilidad organica sin romper la simplicidad del sitio.

### Entradas

- Keywords objetivo
- Servicios prioritarios
- Titulos y descripciones actuales

### Salidas

- Meta titles
- Meta descriptions
- Ajustes de encabezados
- Mejoras semanticas
- Recomendaciones de enlazado interno

### Uso esperado

- Revisar `index.html`, `services.html`, `social-media.html`, `faq.html` y `testimonials.html`.

## 4. Integracion operativa

### Objetivo

Conectar la web con servicios externos sin salir del modelo estatico.

### Entradas

- Endpoint del formulario
- Cuenta de Stripe
- Datos comerciales definitivos

### Salidas

- Actualizacion de `SITE_CONFIG`
- Activacion de formularios reales
- Activacion de enlaces de pago
- Ajustes de mensajes de confirmacion

### Uso esperado

- Configurar `assets/js/main.js`
- Validar flujos de contacto y pago

## 5. QA y validacion

### Objetivo

Comprobar que la web siga siendo funcional, accesible y coherente tras cambios.

### Entradas

- Paginas modificadas
- Integraciones activas
- Escenarios de uso

### Salidas

- Checklist de revision
- Hallazgos
- Riesgos
- Acciones de correccion

### Uso esperado

- Verificar navegacion
- Validar formularios
- Probar responsive
- Revisar accesibilidad base

## 6. Publicacion y continuidad

### Objetivo

Mantener un flujo estable de despliegue y evolucion del proyecto.

### Entradas

- Cambios realizados
- Estado del repositorio
- Configuracion de GitHub Pages

### Salidas

- Documentacion actualizada
- Workflow funcional
- Estado de sesion claro para retomar trabajo

### Uso esperado

- Revisar `.github/workflows/deploy.yml`
- Mantener `README.md`
- Registrar hitos en `checkpoint/README.md`
